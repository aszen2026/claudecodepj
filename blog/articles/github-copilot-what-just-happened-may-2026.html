What Happened

On May 31, 2026, GitHub Copilot sits one day away from the biggest pricing change in its history. Effective June 1, 2026, every Copilot plan moves to usage-based billing, retiring the premium request unit (PRU) model in favor of a new metric called GitHub AI Credits. Credits are burned according to token consumption — input, output, and cached tokens — priced at each model's published API rate, so a long agentic session on an expensive model now costs measurably more than a quick chat on a cheap one.

Each plan ships with a monthly credit allotment matched to its price:

  • Copilot Pro — $10/month in credits
  • Copilot Pro+ — $39/month in credits (now more than 5× Pro's usage allowance)
  • Copilot Business — $19/user (with a promotional $30 in credits, June–August 2026)
  • Copilot Enterprise — $39/user (with a promotional $70 in credits for the same window)

The billing switch arrived alongside a cluster of tightening moves on Individual plans. GitHub paused new sign-ups for Pro, Pro+, and Student tiers, made usage limits visible inside VS Code and the Copilot CLI (including "you've used over 75% of your weekly usage limit" warnings), and reshuffled model access. Opus models were pulled from Pro entirely; Opus 4.7 stays on Pro+, while the older Opus 4.5 and 4.6 are being retired. Separately, a May 20 web changelog removed all Gemini models — plus GPT-5.2 Codex and GPT-5.4 nano — from Copilot Chat on github.com, leaving OpenAI and Anthropic models across the lineup. GitHub also added Claude Opus 4.8 to Pro+, Business, and Enterprise, launching with a steep 15× premium request multiplier that converts into token pricing on June 1.

💡
Code completions and Next Edit suggestions stay free and uncapped under the new model. The meter runs on chat, agents, and other model-backed features — not on inline autocomplete.

Why It Matters

GitHub stated the cause plainly: agentic workflows consume far more compute than the flat-rate PRU structure ever assumed. Coding agents that read repositories, run tools, and iterate over multi-step plans can spend in minutes what a year ago took a developer a month. Flat pricing made every heavy user a loss leader, and the math stopped working.

The winners are predictable consumers — developers who mostly autocomplete and ask occasional questions will likely never touch their credit ceiling. The losers are power users running long agent sessions on frontier models like Opus 4.8; for them, a $10 Pro plan can now be exhausted well before month's end, and the old "fallback to a cheaper model" safety net is gone. Pausing Pro sign-ups is the loudest signal: GitHub would rather protect existing customers' reliability than chase growth it can't profitably serve.

Context

This is the second act of a story that opened in 2025, when Copilot leaned into agent mode and a multi-model lineup spanning OpenAI, Anthropic, and Google. That openness was a marketing win and a cost problem at once — every premium model GitHub resold carried Microsoft's inference bill. The 2026 changes are the correction: narrow the menu to OpenAI and Claude, push the priciest models up-tier, and make customers pay in proportion to the tokens they actually burn.

It also mirrors the broader market. Anthropic's Claude Code and standalone agent tools like Cursor and Windsurf have all wrestled with the same unit economics, and usage-based or credit-metered pricing is becoming the default for agentic coding rather than the exception. GitHub moving its tens of millions of Copilot seats onto token metering effectively ratifies that direction for the whole category.

What To Do Next

Concrete steps before and after the June 1 cutover:

  • Check your real usage now. Open the new limit indicators in VS Code or Copilot CLI and see where you land against your tier's allotment before the meter goes live.
  • Match the model to the job. Reserve Opus 4.8 and other premium models for hard, large-codebase problems; route routine edits and simple agent tasks to cheaper models — the cloud agent now supports fast, cost-efficient options specifically for this.
  • Reassess your tier. Heavy agent users on Pro should weigh Pro+ ($39, 5×+ the allowance and Opus 4.7 access). If you depend on Gemini, note it's gone from web chat — plan around OpenAI/Claude.
  • Teams: use the promo window. Business and Enterprise get bonus credits ($30 and $70) through August 2026 — treat June–August as a free measurement period to baseline real per-developer token spend before budgeting.
💡
If the new pricing doesn't fit, the refund window already closed (cancellations for refunds ended May 20). Going forward, the lever you control is model choice per request — that, not your subscription tier, is what now drives the bill.
